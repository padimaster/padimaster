## What I have built

### Financial services

| | |
|---|---|
| **CREDIT** | Credit origination as a self-service PWA. Membership and loan application collapse into a **single signature ceremony**, identity is proven with biometric liveness against the national ID, and the signed file is delivered to the issuer's core with acknowledgement. Built on a map of **48 external data sources** across eight families, with 34 cut rules and a documented degradation matrix for when a source is down. |
| **Core ledger** | High-throughput financial ledger on **TigerBeetle + Rust** — forced double-entry, event sourcing and full auditability at 100k+ TPS. |
| **RWA tokenization** | Platform for tokenizing real-world assets, with the legal structure and the on-chain representation designed together rather than bolted on. |
| **Payment rails & on-ramps** | Stablecoin payment rails and automated fiat on-ramp flows. |
| **Investment-vehicle structuring** | A ten-phase enforcement harness for structuring collective funds, mercantile trusts and real-asset vehicles, in Ecuador and cross-border. |
| **Cofi** | *Compliance-as-a-Service* for tax and accounting: runs the full monthly tax cycle for SMEs, from electronic invoicing through document ingestion to filing. |
| **AssetsMind** | Asset, inventory and operational-process control for a **Regulated credit union**. |
| **Edu Platform** | An AI financial platform and an autonomous AI financial coach. |

### Privacy and applied cryptography

| | |
|---|---|
| **Quiproof** | Privacy-preserving identity on Ecuador's national eID — NFC/BAC chip reading, certificate-chain validation against the state CSCA, and on-chain age verification through an **Arbitrum Stylus** contract in Rust. Prove you are over 18 without revealing who you are. |
| **AnonGateway** | A **non-custodial** proxy layer over 0xbow Privacy Pools that abstracts service fees while preserving user sovereignty and ragequit rights. |
| **Aegis** | Private XLM transfers on Stellar — sender and recipient unlinkable in public, still decryptable by an authorized auditor. Privacy and supervision in the same system. |
